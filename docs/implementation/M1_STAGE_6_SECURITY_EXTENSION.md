**Intentional successor delta:** Stage 6 adds two default-deny staff capabilities (`trip.preview`, `trip.publish`) and advances the permission registry to version 4; adds the strict customer-facing `PortalTripSnapshotV1` contract; adds a narrow publication source and shared deterministic projection; adds read-only staff Preview and version history; adds serializable Publish with revision/hash conflict detection, durable idempotency, bounded retry, atomic Audit/outbox/event records, immutable snapshot/version rows and an atomic active pointer; adds forward-only migration `0011_stage6_trip_publication.cjs`, qualification/tests and the Stage 6 CI successor wrapper. The extension does not change or relabel the Stage 5 baseline, and it does not grant `portal.access`, change the Portal role, publish mutable workspace state, expose the Staff history API to Portal, or implement Portal grants/access/consumption. Portal application behavior and Stage 7 remain excluded. Internal-only fields are structurally absent from the publication-safe source and strict snapshot. Stage 5's current-tree source-scope writer/scanner is not run against the successor tree because it writes evidence into the immutable Stage 5 generation and its source scope describes Stage 5 bytes.
